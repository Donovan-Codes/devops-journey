# Scripts

Bash and automation written during the roadmap.

## Standards I'm holding myself to

- Every script starts with `#!/usr/bin/env bash` and `set -euo pipefail`
- Every variable expansion is quoted: `"$var"`, not `$var`
- Every script is **idempotent** — running it twice does nothing the second time
- Every script passes [ShellCheck](https://shellcheck.net) with no warnings
- Every script has a comment header: what it does, how to run it, what it assumes
